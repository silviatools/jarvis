# Места, маршруты и бесплатные квоты

Навык в Настройки → Ассистент → «Места и маршруты». Доступен в боте
владельца, чате сайта и голосом, включая планшет. Переключатель —
«Навыки ассистента → Места, маршруты и пробки».

Пример: «Я в Vegas на МКАД, сообщи, когда до дома будет меньше часа».
Ассистент читает сохранённые места и адреса `settings.homeAddress` /
`settings.workAddress`, уточняет неоднозначный Vegas, сохраняет выбранные
координаты и вызывает `route_watch`. Проверки идут каждые 5 минут,
по умолчанию 12 часов. Маршрут считается от выбранной точки отправления,
а не от меняющейся геопозиции телефона. Для уведомления нужны Telegram-бот
и подключённый личный Telegram владельца.

Demo-доступ Mapbox обозначен поставщиком как доступ для тестирования и
прототипов; бессрочная доступность для постоянного использования не гарантирована.
Страницы signup и demo-access описывают условия несколько по-разному:
указанные квоты следует сверять в собственном кабинете. Без карты сервис
останавливает доступ при лимите; автоматического повышения тарифа нет.
Отдельный продукт Traffic Data не используется — нужен именно Directions.

## Подключение без платного продолжения

1. Зарегистрировать Mapbox через **Start without a card**, без платёжного метода.
2. Ввести токен Directions в «Места и маршруты». Альтернатива для сервера —
   переменная `MAPBOX_TOKEN`. Джарвис не регистрирует платные аккаунты и
   не повышает тарифы.
3. Для поиска адресов используется бесплатная квота Search существующего
   ключа `settings.tomtomKey`; можно задать отдельный ключ в этом блоке
   или через `TOMTOM_KEY`. Для строгого отсутствия списаний используйте
   аккаунт без платного продолжения. Координаты можно ввести вручную —
   тогда поиск и его ключ не нужны.
4. Один раз выбрать точку «Дом» / «Работа». Поиск возвращает кандидатов,
   не выбирает первый Vegas автоматически. Общие адреса сохраняются
   в прежних настройках; выбранные точки — в данных навыка.

У Джарвиса дополнительные, неизменяемые через инструменты ИИ лимиты:
**5000 вызовов Mapbox** и **2000 поисков TomTom** за скользящие 32 дня.
Попытка резервируется на диске до HTTP-запроса, включая ошибочные попытки.
Лимит не обнуляется при смене ключа или перезапуске. По его достижении
запросы не отправляются, наблюдение завершается с `quota_exhausted`
и уведомлением. Счётчик относится к новому навыку; запросы других
приложений и старой карточки в него не входят. Защита на стороне сервиса
без платёжного метода важна независимо от локального счётчика.

## Значение результата

Mapbox объединяет доступные наблюдения и типичную статистику. API не
сообщает время последнего наблюдения для каждого участка, поэтому
Джарвис не обещает полного покрытия текущими измерениями и совпадения
с Яндекс Навигатором. Ссылка в уведомлении открывает новый расчёт
Яндекс Карт; она не воспроизводит вариант Mapbox.

Маршруты сравниваются по `duration`, порог проверяется **строго в секундах**.
Чтобы неизвестные пробки не считались свободной дорогой, для наблюдения
требуется известный уровень congestion минимум на 80% длины маршрута.
Остальные варианты можно показать, но уведомление по ним не срабатывает.
Нулевое, отрицательное, нечисловое время, ошибки и старый результат не
могут вызвать уведомление об улучшении дороги. После ошибки доставки
перед повторной отправкой заново проверяется маршрут. Отмена и выключение
навыка проверяются также после сетевого запроса.

## Хранение и проверка

`DATA_DIR/jarvis_routes.json` — места, наблюдения, счётчики; включён в бэкап.
`DATA_DIR/jarvis_route_keys.json` — ключи (600), исключены из бэкапа и
статической раздачи. Ключи не выдаются модели и через status API.

`python -m unittest test_routes test_plan` — проверки API-контрактов,
порогов, квот, перезапуска, ошибок, приватности, HTTP и обоих циклов ИИ.
Все внешние запросы и доставка сообщений в тестах подменяются.
Живой запрос к Mapbox без токена не выполнялся.
