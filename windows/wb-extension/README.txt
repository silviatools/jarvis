Джарвис — WB на Windows 10. Прототип 0.1.2

1. Установите актуальный Google Chrome (120 или новее).
2. Создайте отдельный профиль Chrome «Джарвис» и войдите в Wildberries.
   Проверьте, что открываются покупки и доставки.
3. На сайте Джарвиса: Настройки → Маркетплейсы → «WB на Windows-ПК».
   Скачайте ZIP расширения и распакуйте в постоянную папку, например
   C:\Jarvis\wb-extension. Не удаляйте папку после установки.
4. В ЭТОМ ЖЕ профиле откройте chrome://extensions, включите «Режим
   разработчика», нажмите «Загрузить распакованное расширение» и выберите
   папку с manifest.json.
5. В настройках Джарвиса создайте ключ ПК. Откройте расширение через
   значок пазла в Chrome. Укажите HTTPS-адрес Джарвиса и ключ wbpc_…,
   нажмите «Подключить» и разрешите доступ только к своему сайту Джарвиса.
6. Через несколько секунд в настройках сайта ПК должен появиться в сети.
   Нажмите «Проверить вход», затем «Доставки» или «Покупки».
7. Спросите Джарвиса в Telegram: «Что у меня едет с Wildberries?».

Как работает
Расширение примерно каждые 30 секунд забирает задания с сайта Джарвиса.
Для чтения оно открывает свою фоновую вкладку, не трогая вашу вкладку
с покупками. Передаёт только поля заказов из ответов, которые запрашивает
сам WB. Пароли, cookies, заголовки авторизации и коды входа не передаются.
Чтение может занять до 90 секунд. История ограничена загруженными WB
данными (до 40 записей); это не гарантированная выгрузка всей истории.
Числовые цены с неизвестной единицей измерения не показываются.

ПК должен быть включён и не спать, Chrome с этим профилем должен работать.
Не нужен Python, Node.js, белый IP, мобильный прокси или проброс портов.
После перезагрузки войдите в Windows и запустите этот профиль Chrome.
Автозапуск и работа без входа в Windows в прототип не входят.

Если нет связи
Откройте расширение и нажмите «Обновить связь». Проверьте адрес сайта,
интернет и ключ. Создание нового ключа отключает старый.
Если WB просит войти или пройти проверку — сделайте это вручную.
Если структура ответов WB изменилась, расширение сообщит, что кабинет
не прочитан, вместо ответа «заказов нет». Это потребует обновления адаптера.

Логи
Последние 6 проверок сохраняются автоматически в самом расширении,
включая задания от Джарвиса. Откройте расширение → «Диагностика WB».
«Проверить WB» запускает отдельную проверку доставок даже без сервера.
После завершения нажмите «Скопировать логи» и вставьте отчёт в чат.
В отчёте — версия расширения, этап чтения, состояние загрузки вкладки,
счётчики, адреса API без query и динамических сегментов, HTTP-статусы,
названия полей JSON и их типы. Значения полей, содержимое заказов,
cookies, ключи и коды не записываются. Логи остаются на этом ПК;
на сервер загружается обычный результат чтения, без диагностики.
«Очистить» удаляет сохранённые отчёты.

Обновление
Замените файлы в той же папке расширения новыми из ZIP. Нажмите
круговую стрелку на карточке расширения в chrome://extensions.
Обновите вкладки WB. Не удаляйте и не устанавливайте расширение заново:
при обновлении в прежней папке адрес и ключ подключения сохраняются.

Отключение
«Остановить» в расширении удаляет локальный ключ. «Отключить ПК» на
сайте отзывает ключ и возвращает WB к старому серверному подключению.
Для нового подключения потребуется создать и ввести новый ключ.
