Поля товаров и ПВЗ

Здесь собраны поля, которые выбранный магазин отдал для загруженных заказов. Обычный ответ Джарвиса: название товара, цена и статус. Дополнительные сведения используются только по вашему прямому запросу. Отметьте поля для таких подробных ответов; если ничего не выбрано, расширение использует доступные безопасные поля.

order / item — заказ и конкретная позиция; delivery / office — доставка и ПВЗ; product — карточка товара (её цены могут отличаться от цены заказа); status — последний статус; page — данные, прочитанные со страницы. Только у WB для RUB-заказов item.price подтверждён в копейках: 75500 → 755 ₽. Единицы других чисел и коды состояний оплаты требуют проверки.

Примеры могут содержать сведения о ваших товарах и ПВЗ. Каталог хранится на ПК. На сервер отправляются основные данные и только выбранные дополнительные поля — до 100 на позицию, с ограничением общего размера. Cookies, токены, подписи и банковские реквизиты исключены. Каталог охватывает загруженные ответы WB, а не все возможные данные маркетплейса.

page.binding показывает связь: matched_article_or_rid — товар сопоставлен; status_only — только статус; unmatched_page_product — отдельная карточка страницы; unmatched_api_item — данные API, ещё не связанные со статусом. Не сопоставляйте такие записи по порядку.

Ozon: цена берётся из денежной подписи товара в заказе; числовые поля без валюты не пересчитываются. Статусы относятся к посылкам, которые могут отличаться внутри одного заказа. Каталоги и выбор полей WB и Ozon хранятся отдельно.
