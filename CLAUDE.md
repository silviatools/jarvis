# Джарвис — заметки для Claude

Личное приложение: сайт-SPA (`index (9).html`) и сервер (`jarvis.py`) с Telegram-ботом, ассистентом и напоминаниями.
Деплой — Railway из ветки `main`; данные лежат в `DATA_DIR` (Volume). Отвечать пользователю по-русски, коротко.

## Новый навык ассистента — ВСЕГДА регистрировать в настройках

Любой новый навык Джарвиса (то, что умеет ассистент в боте, чате или голосом) должен появляться в списке
**Прочее → Настройки → Ассистент → «Навыки ассистента»**: с названием, описанием и переключателем.
Тот же список (компонент `AssistantSkillsCard`) показан и во вкладке «Телеграм». Без записи в этом каталоге навык считается не сделанным.

Что нужно сделать:

1. **Запись в каталоге** — словарь `{"id", "title", "risk", "default", "desc", "tools": [имена инструментов]}`:
   - `risk` — `read` (чтение), `create` (создаёт файлы), `write` (действия с подтверждением), `danger` (опасно);
     подписи и цвета бейджей — `riskLabel` / `riskCls` в `AssistantSkillsCard` (`index (9).html`); новый тип риска добавлять туда же;
   - `default` — включён ли по умолчанию; `desc` — по-человечески: что умеет, как использовать, ограничения
     (например, «превью требует LibreOffice на сервере»).
2. **Где хранить запись:**
   - навыки личного Telegram (Telethon) — в `TG_SKILLS` в `tg_tools.py` (там же проверка, что все `tools` существуют);
   - остальные — в своём модуле списком `SKILLS` (образец — `deck_skill.py`) и добавить его в выдачу `/api/tg/skills`
     в `jarvis.py` (`deck_skill.SKILLS + tg_tools.skills_catalog()`).
3. **Переключатель** хранится в `data.telegramSkills[<id>]` (синхронизируется как обычные данные). Выключенный навык
   не должен попадать ни в список инструментов ИИ (оба цикла `_assistant_loop_claude` / `_assistant_loop_openai`),
   ни в исполнитель (`execute_assistant_tool`), ни в системный промпт (`build_assistant_system_prompt`).
   Проверка включённости — функция `skill_on(state)` в модуле навыка (по умолчанию — `default`).
4. **Данные навыка** на диске — добавить файл в `data_names` (бэкап в `jarvis.py`) и в `.gitignore`.
5. **Проверить:** навык виден в списке и переключается; при выключении инструменты исчезают из запроса к ИИ;
   сквозной тест с подменой ответов модели и Telegram API.

## Карта проекта

- `jarvis.py` — HTTP-сервер, минутный цикл напоминаний (`_tick`), ассистент (инструменты, циклы Claude/OpenAI),
  «Учёба» (расписание rasp.rea.ru, вложения заданий, напоминания по заданиям), бэкапы.
- `tg_bot.py` — возможности бота: форматирование (HTML Telegram), чеклисты, файлы, опросы, картинки, расшифровка
  голосовых, память диалога (TTL 10 мин, название диалога под ответом), входящие вложения.
- `tg_tools.py` / `tg_user.py` — личный Telegram пользователя (Telethon): чтение, поиск, файлы, ответы, отправка.
- `file_tools.py` — чтение и создание docx/xlsx/pptx/pdf и др.; шрифты для PDF — `assets/fonts`.
- `study_skills.py` — навыки «Учёбы»: «Сбор информации по задаче» (кнопка в карточке задачи, фоновый агент только на чтение,
  отчёт в бот) и «Контроль учебных чатов» (ежедневная проверка, настройки в `data.studyChats`); запуск и рассылка — в `jarvis.py`
  (`start_study_brief`, `study_chats_scan`). Отчёты бота хранят контекст: `tg_bot.remember_anchor` / `restore_anchor`
  (ответ на сообщение бота возвращает диалог и после паузы).
- `mail_skill.py` — навык «Почта Mail.ru» (только чтение): ящики по IMAP (Настройки → Почта), индекс заголовков всех папок
 (у Mail.ru IMAP SEARCH не ищет по тексту), инструменты `mail_*`, фоновая проверка раз в 90 с без IDLE; уведомления —
 общая маршрутизация, категория `mail:<id ящика>`. Пароли приложений — `DATA_DIR/jarvis_mail/` (600, не в бэкапе). Тесты — `test_mail.py`.
- `deck_builder.py` / `deck_skill.py` — навык «Презентации»: движок слайдов (темы, макеты, проверка качества) и интеграция.
- `index (9).html` — всё приложение одним файлом (React через Babel в браузере); раздел «Учёба» — `StudyView`.
  «Бюджет» на телефоне (уже 768px, хук `useBudgetMobile`) — карточки вместо таблиц, редкие действия в `BudgetActionSheet` («⋯»),
  быстрые отметки с тостом «Отменить» (`useBudgetUndo`); все `Modal` внутри `BudgetView` на телефоне — шторки снизу
  (`ModalSheetContext`). ПК-вёрстку раздела мобильные правки не меняют.
- `requirements.txt` — зависимости ставит Railway при деплое; новые библиотеки добавлять сюда.
- `nixpacks.toml` — системные пакеты для сборки на Railway (`aptPkgs`): LibreOffice и poppler для превью презентаций;
  нужен новый системный пакет — добавлять сюда.

## Как проверять

- Серверную логику и ассистента — скриптами с подменой `requests.post` и `tg_bot.api` (без настоящих Telegram/ИИ).
- Интерфейс — локальным запуском `python jarvis.py --port 8765` с временным `DATA_DIR` и браузером (Playwright);
  вход на сайт — cookie `jarvis_auth`. CDN-скрипты (React, Babel, Tailwind) из песочницы недоступны — подменять локальными.
- Пуш в `main` — только по явной просьбе пользователя.
