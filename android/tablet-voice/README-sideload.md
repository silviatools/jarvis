# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.11 (12)**. Если нет — старый APK.

## Поставить

С 1.2–1.10 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.11 (12)**.
4. **Слушать**. «Джарвис, какая сегодня погода» — `wake` → `stream` → ход. Без самопроизвольного `abort стоп`.
5. Пока говорит — чётко «стоп» → `barge-in стоп` / `abort стоп`.
6. Только «Джарвис» и тишина — `тишина — без трафика`.
