# Джарвис на планшете — установка APK (One UI / Tab A9)

Sideload, Play Store не нужен. Нужен интернет и код входа на сайт Джарвиса.

На главном экране и в уведомлении «слушаю» должна светиться версия **1.2 (3)**. Если видите 1.0 / 1.1 или нет номера — стоит старое приложение.

## Поставить (сначала удалить старое)

Debug и первые сборки могли быть с другой подписью. Смесь debug/release даёт ошибку вроде «конфликт подписи» / «не обновить приложение». Тогда обновление не встаёт, а старое открывается.

1. Настройки → Приложения → Джарвис → **Удалить**.
2. Скопируйте только `jarvis-tablet-release.apk` (версия 1.2).
3. Настройки → Безопасность → Установка неизвестных приложений → разрешите источнику.
4. Откройте APK → Установить → Открыть.
5. На экране крупно должно быть **1.2 (3)**. Если нет — это не этот файл.
6. Разрешите **микрофон** и **уведомления**. Уведомление не смахивайте.

После удаления вход (URL и код сайта) придётся ввести снова.

Дальше ставьте только release. Debug и release из этой папки подписаны одним ключом, но на планшете держите один файл — release.

## Войти

1. Адрес сайта, например `https://xxx.up.railway.app`.
2. Код — тот же, что на странице входа сайта.
3. «Войти и сохранить».
4. «Слушать».

Ключи ИИ: Прочее → Настройки → Ассистент.

## Чтобы One UI не убил слух

1. В приложении — **«Не экономить батарею»**.
2. Настройки → Батарея → **Никогда не переводить в сон** для «Джарвис».
3. Недавние → Джарвис → замок.
4. Автозапуск / работа в фоне — включить.
5. Планшет лучше на зарядке.

## Как говорить

«Джарвис, …». После ответа ~20 с без имени. Пока отвечает — перебейте голосом или «стоп».
