# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана, без прокрутки: **Джарвис 1.5 (6)**. Если нет — старый APK.

## Поставить

С 1.2–1.4 — **поверх**, подпись та же. Удалять не нужно.

Если система ругается на подпись — удалите «Джарвис» и поставьте `jarvis-tablet-release.apk` заново.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить / Установить.
3. Наверху **Джарвис 1.5 (6)**.
4. **Слушать**. Индикатор микро не должен гаснуть, пока слух включён.

## Что изменилось

В 1.4 микро гас на `STT destroy (think)` и `AudioRecord stop (после TTS)`.
В 1.5 AudioRecord держится всё время; STT на ход/ответ не уничтожается. Пока Джарвис говорит — эхо не уходит в команду, перебить можно голосом. «жервис» = «джарвис».
