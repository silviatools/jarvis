# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.14 (15)**. Если нет — старый APK.

## Поставить

С 1.2–1.13 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.14 (15)**.
4. После ответа экран: **Слушаю без имени N с**, не «Жду Джарвис».
5. Когда «Жду «Джарвис»» — фон без имени не ход. В журнале `нет имени — игнор`.
6. После N=0 — снова «Жду «Джарвис»», поздних stream нет.
7. Barge-in и echo как в 1.13.
