# Джарвис на планшете — установка APK (One UI / Tab A9)

По умолчанию экран без журнала. Версия: кнопка **«Журнал»** справа сверху — наверху **Джарвис 1.23 (24)**. Если нет — старый APK. Обратно — **«Экран»**.

## Поставить

Файл версии **1.23** открывается с телефона по прямой ссылке:
https://github.com/silviatools/jarvis/releases/download/tablet-1.23/Jarvis-tablet-1.23.apk
Кнопка на сайте: **Ещё → Прочее → Настройки → Газета → «Скачать приложение»**.
Имя файла: `Jarvis-tablet-1.23.apk`.

С 1.2–1.22 — **поверх**, подпись та же.

1. Нажмите «Скачать приложение» и дождитесь файла `Jarvis-tablet-1.23.apk`.
2. Откройте → Обновить.
3. «Журнал» → наверху **Джарвис 1.23 (24)**. В журнале на фразе: `stt поток`, затем `stt хвост`.
4. Звук на колонку (BT/кабель): пока говорит — сам себя не перебивает.
5. Реальный «Джарвис …» поверх ответа — ход. Кусок своего текста без имени — `barge-in без имени — эхо`, TTS продолжается.
6. В журнале `out=bt` / `out=speaker`. Длинный stt не режется молча — в конце «…».
7. Пауза конца фразы — первый ползунок, по умолчанию 2 с. Окно без имени — второй, по умолчанию 5 с (0 — сразу снова «Джарвис»). Начал говорить внутри окна — фраза дослушивается и после нуля.

## Автоматическая газета на Pantum

1. Откройте Jarvis → **Ещё → Настройки → Газета** и включите выпуск и автоматическую печать.
2. Оставьте IP пустым: планшет ищет Pantum через mDNS/IPP. Если роутер блокирует mDNS, впишите IP принтера с его страницы конфигурации; порт обычно `631`, путь — `/ipp/print`.
3. Один раз откройте приложение и нажмите **«Журнал»**. «Слушать» не нужно: сразу идут строки `газета:`. Дальше планшет сам опрашивает сервер и принтер примерно раз в минуту, в том числе после перезагрузки и при выключенном микрофоне.
4. Планшет должен быть подключён к тому же Wi‑Fi, что и принтер. SIM/LTE используется для связи с облачным Jarvis, локальное задание уходит принтеру только через Wi‑Fi. VPN (Clash, sing-box, AdGuard) с адресом 198.18.0.1 забирает TCP до принтера: выключите VPN или разрешите локальную сеть принтера.
5. Кнопка **«Напечатать проверочный выпуск»** создаёт отдельное задание. Без неё и при выключенной автопечати планшет всё равно проверяет сохранённый IP.
6. На сайте, Настройки → Газета: **Планшет: на связи** или **нет связи** (опроса не было 3 минуты) и **Принтер: виден** или **не отвечает**.

Агент сначала запрашивает возможности принтера и выбирает объявленный формат: PDF, PCLm, PWG Raster, PNG или JPEG. Идентификаторы успешно напечатанных выпусков хранятся на планшете и сервере, поэтому ежедневная проверка не печатает второй экземпляр.
