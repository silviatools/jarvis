# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.12 (13)**. Если нет — старый APK.

## Поставить

С 1.2–1.11 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.12 (13)**.
4. **Слушать**. После «wake готов, прогрет» — короткий пик «услышал».
5. Первое «Джарвис, какая погода» сразу после старта должно дать `wake` → `stream` → ход.
6. Быстрый перебив одной фразой во время ответа — `barge-in wake`, фраза целиком.
7. Сказанный «стоп» во время речи — `barge-in стоп`. Самопроизвольного abort быть не должно.
