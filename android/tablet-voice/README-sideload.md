# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.13 (14)**. Если нет — старый APK.

## Поставить

С 1.2–1.12 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.13 (14)**.
4. **Слушать**. После «wake готов, прогрет» первая секунда не даёт wake с ТВ/буфера.
5. После ответа, через 1–3 с, без имени: «Да, про погоду в Москве» и «Что ты умеешь?» — ход, не `echo`.
6. Длинная фраза — конец по паузе ~1 с, не обрезка «Москв» / «что слу». Потолок ~30 с.
7. Сказанный «стоп» во время речи — `barge-in стоп`. Перебив именем — `barge-in wake`, `echo сброшен`.
