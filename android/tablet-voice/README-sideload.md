# Джарвис на планшете — установка APK (One UI / Tab A9)

Sideload, Play Store не нужен. Нужен интернет и код входа на сайт Джарвиса.

## Поставить

1. Скопируйте **новый** APK (`jarvis-tablet-release.apk`, версия 1.1) на планшет.
2. Настройки → Безопасность → Установка неизвестных приложений → разрешите источнику (Файлы / Chrome).
3. Откройте APK → **Обновить** поверх старого (подпись та же). Если система ругается — удалите старое «Джарвис» и поставьте снова; URL и код ввести ещё раз.
4. Разрешите **микрофон** и **уведомления**. Уведомление «Джарвис слушает» не смахивайте — без него Android 16 заберёт микрофон.

## Войти

1. В поле адреса — публичный URL Джарвиса, например `https://xxx.up.railway.app` (без слэша на конце).
2. Код — тот же, что на странице входа сайта.
3. «Войти и сохранить» — на сервере создаётся токен устройства.
4. «Слушать».

На сайте должны быть ключи ИИ: Прочее → Настройки → Ассистент.

## Чтобы One UI не убил слух

1. В приложении нажмите **«Не экономить батарею»**.
2. Настройки → Батарея → Ограничения фона → **Никогда не переводить в сон** для «Джарвис».
3. Недавние приложения → Джарвис → замок (закрепить).
4. Настройки → Приложения → Джарвис → Автозапуск / работа в фоне — включить.
5. Планшет лучше держать на зарядке.

## Как говорить

Скажите «Джарвис, …» и команду. После ответа ~20 секунд можно говорить без имени — кнопку «Слушать» нажимать снова не нужно. Пока отвечает — перебейте голосом или «стоп». Если уведомление пропало, откройте приложение: слух поднимется сам, если он был включён.

Нужны русские голоса Google (распознавание) и TTS. Обычно уже стоят на Tab A9.
