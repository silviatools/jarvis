# Джарвис на планшете — установка APK (One UI / Tab A9)

По умолчанию экран без журнала. Версия: кнопка **«Журнал»** справа сверху — наверху **Джарвис 1.17 (18)**. Если нет — старый APK. Обратно — **«Экран»**.

## Поставить

С 1.2–1.15 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. «Журнал» → наверху **Джарвис 1.17 (18)**.
4. Звук на колонку (BT/кабель): пока говорит — сам себя не перебивает.
5. Реальный «Джарвис …» поверх ответа — ход. Кусок своего текста без имени — `barge-in без имени — эхо`, TTS продолжается.
6. В журнале `out=bt` / `out=speaker`. Длинный stt не режется молча — в конце «…».
7. Пауза конца фразы — первый ползунок, по умолчанию 2 с. Окно без имени — второй, по умолчанию 5 с (0 — сразу снова «Джарвис»). Начал говорить внутри окна — фраза дослушивается и после нуля.
