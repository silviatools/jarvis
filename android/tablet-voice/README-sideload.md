# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.9 (10)**. Если нет — старый APK.

## Поставить

С 1.2–1.8 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.9 (10)**.
4. **Слушать**. В журнале сразу `rec start`. Первый раз качает модель слуха (~45 МБ) — приложение уже работает, wake появится после «wake готов».
5. «Джарвис, привет» — в журнале `wake`, затем `stream`, ответ вслух. Пока говорит без «стоп»/«джарвис» — `echo`, нового хода нет.
6. «Стоп» или «джарвис» **во время озвучки** — сразу `barge-in стоп` / `barge-in wake`, речь рвётся. Не `echo стоп`. Тишина после ответа — без `stream`.
