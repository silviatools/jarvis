# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана, без прокрутки, крупно жёлтым: **Джарвис 1.3 (4)**. То же в уведомлении. Если этого нет — стоит старый APK.

## Поставить

С 1.2 (3) — **поверх**, подпись та же. Удалять не нужно, вход сохранится.

Если система ругается на подпись (ставили debug или сборку до 1.2) — удалите «Джарвис» и поставьте `jarvis-tablet-release.apk` заново (URL и код ввести снова).

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить / Установить.
3. Сразу наверху должно быть **Джарвис 1.3 (4)**.
4. Микрофон и уведомления. Уведомление не смахивать.

## Журнал слуха

Прокрутите чуть вниз: блок «Журнал слуха (МСК)», последние строки, автоскролл.

Когда микрофон щёлкает, смотрите пары:

- `STT destroy` / `STT create` / `STT startListening` подряд — лишний рестарт
- `STT error 7 NO_MATCH` или `6 SPEECH_TIMEOUT` — тишина, это норма; не должно быть сразу `destroy`
- `watchdog: слух мёртв` — служба сама подняла слух
- `AudioRecord start/stop` часто — переключение STT ↔ запись
- `barge-in energy` / `AEC mute echo` — эхо TTS или настоящий перебив
- `FGS lost` — Android снял службу

Токен и URL в лог не пишутся.

## Войти

URL сайта и код входа. «Слушать». Ключи ИИ — Настройки → Ассистент.

## One UI

Не экономить батарею; не переводить в сон; замок в недавних; автозапуск. Лучше на зарядке.
