# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.7 (8)**. Если нет — старый APK.

## Поставить

С 1.2–1.6 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.7 (8)**.
4. **Слушать**. «Джарвис, привет» — в журнале `results`, ответ вслух. Пока говорит — в журнале `STT echo ignore`, нового хода нет.

Пока отвечает, перебить можно словом «стоп».
