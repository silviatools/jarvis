# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана, без прокрутки: **Джарвис 1.6 (7)**. Если нет — старый APK.

## Поставить

С 1.2–1.5 — **поверх**, подпись та же. Удалять не нужно.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить / Установить.
3. Наверху **Джарвис 1.6 (7)**.
4. **Слушать**. Скажите «Джарвис, привет» — в журнале должны быть `onBeginningOfSpeech` и `STT results`.

## Почему 1.5 оглох

AudioRecord и Google STT держали микро вместе. AudioRecord забирал поток, STT слышал тишину → вечный `error 7 NO_MATCH`, без `onBeginningOfSpeech`.

В 1.6 один клиент: STT на всё время (не destroy на ход/ответ). AudioRecord только если STT умер во время TTS.
