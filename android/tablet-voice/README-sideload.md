# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана, без прокрутки, крупно жёлтым: **Джарвис 1.4 (5)**. Если этого нет — стоит старый APK.

## Поставить

С 1.2 / 1.3 — **поверх**, подпись та же. Удалять не нужно, вход сохранится.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить / Установить.
3. Сразу наверху должно быть **Джарвис 1.4 (5)**.
4. Нажмите **Слушать**.

## Журнал

«Скопировать журнал» — вся сессия в буфер (не только видимые строки).

E11 (`ERROR_SERVER_DISCONNECTED`) — Google STT оборвал сессию, часто после того как TTS и распознаватель дерутся за микрофон. В 1.4 после ответа STT поднимается один раз; при E11 пауза 4–30 с, не щелчки каждые 3 с.

## One UI

Не экономить батарею; не переводить в сон; замок в недавних.
