# Джарвис на планшете — установка APK (One UI / Tab A9)

Наверху экрана: **Джарвис 1.10 (11)**. Если нет — старый APK.

## Поставить

С 1.2–1.9 — **поверх**, подпись та же.

1. Скопируйте `jarvis-tablet-release.apk`.
2. Откройте → Обновить.
3. Наверху **Джарвис 1.10 (11)**.
4. **Слушать**. В журнале сразу `rec start`. Первый раз качает модель слуха (~45 МБ).
5. Одной фразой: «Джарвис, какая сегодня погода в Москве» — `wake` → `stream` с preroll 1.5 с, ход целиком, не обрубок.
6. Пока говорит — «Джарвис, погода в Москве» → `barge-in wake`, `echo сброшен`, ход «погода в Москве», не `echo`.
7. Пока говорит или сразу после — «стоп» → `abort стоп`, без нового `stream`/`ход`.
8. Только «Джарвис» и тишина — `тишина — без трафика`, без «Да?» и без эфира ТВ.
